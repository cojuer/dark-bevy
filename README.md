# dark-bevy

`dark-bevy` is an open-source engine for Thief Gold/Thief II intended to use
data from legally owned installations.

Project is unofficial and is not affiliated with or endorsed by the games' developers or publishers.

> IMPORTANT
> This project is at "Hello world" state. Do not take it seriously.

## Current status

Nothing is working.

## Building

Install `cargo` with [`rustup`](https://rustup.rs/), run:

```console
cargo build
cargo run
```
